## 两个版本各自的核心几何

**v1「L · 落点」**（外框 1:φ）
```
L_W(318) + GAP(121) + DOT(75) = 514 ≡ W
= W/φ + SW/φ + SW/φ² = H/φ² + H/φ⁴ + H/φ⁵ = H × 0.618034 = W     误差 0.000%
```

**v2「L · 柚子」**（外框 1:1）
```
L_W(438) + GAP(75) + FRUIT(317) = 830 ≡ W = H
= (2SW + SW/φ³) + SW/φ² + SW·φ = SW(2φ+1) = SW·φ³ = H              误差 0.000%
```
加柚子之后，画框**自己变成了正方形** —— 不是设计师选了正方，是恒等式不允许它不是。
半径只有 3 档且两两成对：端头·外凸转角 = SW/2、内凹转角·蒂窝 = SW/φ²、叶弧 = SW/φ → 圆的用法统一而不乱。
配色只有两支且分工明确：**粉给字**（L + 叶 + 字标）、**黄给果**（仅柚子果身）。
