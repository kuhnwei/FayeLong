# 00 · START HERE —— v2「L · 柚子」（可爱活泼版）

**在 v1「L · 落点」的骨架上改了三件事**：直角语法 → 圆语法，方形句点 → 一颗柚子，松墨深青 → **樱粉 + 柚黄**。

配色分工一句话：**粉给字，黄给果** ——
- **樱粉 `#F2759F`**（H 339.8°）：字母 L + 叶 + 字标，它决定「可爱」
- **柚黄 `#EDC62A`**（H 48.0°，正黄区）：只给柚子果身，它负责「这是一颗柚子」

> 「一句被听清的话，结成了一颗果子。」
> 竖笔 = 声音 · 横笔 = 纸上的行 · **柚子 = 听懂之后的收获**

## 三条不能记错的事

1. **≤32px 建议换 favicon 版**。它与主标**同一套比例**（果 = SW·φ、间隔 = SW/φ²），唯一差别是外框取 **960**（16/32/48/64 全整除 → 小尺寸落在整像素上），主标的 830 不能（16px 缩放系数 51.875，边缘发虚）。
   16px 实测：笔 3.78px、果 6.12px 可辨；**间隔 1.45px 会并拢** —— 这是 16px 格子里塞下 8px 果子 + 3.8px 笔画的物理下限，已写进 spec，不假装没问题。
2. **粉不是万能字色**。樱粉于纸底只有 2.45:1：当标志、大标题、图标都够用，但**别拿它当正文或小字号颜色** —— 那种场景换深樱粉 `#C2185B`（≈ 5.2:1）。
3. **外框是正方形，因为恒等式不允许它不是**：
   `L_W + GAP + FRUIT = (2SW + SW/φ³) + SW/φ² + SW·φ = SW(2φ+1) = SW·φ³ = H`
   代入 `438 + 75 + 317 = 830 ≡ W`，**误差 0.000%** —— 三个宽度一个自由度都没有。
4. **单色版里柚子的「黄」和笔画的「粉」都会消失**，只剩一颗扁圆 + 叶子 + 字母的形状在说话。这是几何事实、属预期行为，不要用描边去「修」。
