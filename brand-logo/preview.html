FayeLong 标志方案 · 「L · 落点」

提案轮 v1.0 · 单方向极致交付 · 比例系统 φ · 几何由 06-source/build_logo.py 参数化生成

字母 L（FayeLong / Listening / Language）＋ 一个句点。竖笔是声音、横笔是纸上的行、句点是被听清的那一个字——一声落下，写成一句。整个标志只由两个元素构成，且外框宽度被黄金比必然切成三段：318 + 121 + 75 = 514，没有一段可以自由取值。

① 元素预算卡

元素清单：字母 L（主）／句点（配）—— 2 / 3 达标
语义来源：L = 首字母 + Listening + Language + Learn
　　　　　句点 = 一句话的最小单位（产品的「一句一页」）
主角占比：L 占 97.2%　句点占 2.78%（<10% 点缀纪律）
删减测试：删句点→「句」没了、只剩一个普通字母 → 保留
一元素多义：句点 = 句号 + 听写落点 + 刚写下的那个字（三义均可讲清）
关系语义：点落在横笔（基线）上 →「落在句子上」，不是漂浮装饰

② 色彩判断卡

行业地图：英语学习 = 教育蓝海（百词斩/扇贝/流利说全蓝）
　　　　　+ 多邻国高饱和亮绿（游戏化）
　　　　　→ 空位 = 低饱和深墨青
主色：#0E3B34 松墨｜HSV 170.7° 76% 23%
点缀：#D98A3D 焰琥珀｜只给句点，占比 2.78%，绑「被听清的那一下」
底色：#F2F5F3 纸底（带 3% 主色倾向，非纯白）｜深底 #0B2A26
硬判据：灰度明度差 89.6% >20% ✓
　　　　｜四格式齐全 ✓｜单色可逆 ✓
差异一句话：他们亮绿求「嗨」，我们深墨青求「静」

③ 风格语法卡

连续谱定位：直角端（偏右三区）——平头端、直角转角、零圆角
理由：精听／听写是「精确」的动作（逐词校验、0 容差），语法就该精确
形态决策：端头平切／内角直角／无描边／无渐变
　　　　　／无投影／无外发光
软度唯一出处：句点方块保留 r=17.71 微圆角 = DOT/φ³
字标规则：大写高 = 笔宽 SW = 196（= H/φ³）
一致性：直角语法 ≈ 95%｜混用声明：句点圆角 =「刚落下、还未凝固」
禁项自查：无渐变球／无外发光／无半透明叠圆／无 NFT 蓝紫 ✓

01Hero 主标

纯图形 · 彩色 · 透明底可用（此卡为纸底）

一声落下，写成一句

竖笔与横笔是同一支笔画的两段、等宽——它是一支「笔」，不是拼起来的两个零件。句点底边与横笔底边严格共线：它落在句子上，而不是飘在旁边。句点右缘与外框右缘齐平，整幅右侧干净闭合。

外框 1 : φ笔宽 H/φ³直角语法句点 2.78%零渐变 · 零投影

撞脸自查（几何特征级原创性自查，非商标法律检索）

对标它的图形语言我们与它的差异
多邻国 Duolingo高饱和亮黄绿 + 圆润猫头鹰吉祥物，靠「角色亲和」我们无吉祥物、无亮绿、纯几何字形；靠「形状纪律」而非角色讨喜
百词斩蓝色圆角方块容器 + 中文名，靠「容器化」我们不用容器方块、不用教育蓝；标志是无外框的开放字形
扇贝单词蓝色 + 生物具象（贝壳）我们完全抽象，不含任何具象物
每日英语听力／可可英语耳机／扬声器／同心声波弧 + 蓝，靠「音频图标」我们不做并列的音频图标；「声音」含义由竖笔（厚重笔画）承担，不额外贴喇叭
音频类通用（SoundCloud 等）水平波形长条阵列 + 橙色我们用单支笔画而非长条阵列；橙色只出现在一个句点上，占比 <3%

语义安全审查

检查项结论

10候选对比表（内部发散 · 探索成本不摊给用户）

候选方向一句话气质落选原因
声纹 L（竖笔做振幅调制）声音在笔画里起伏数学自洽、也真做成了矢量——但 3 波瓣读成「螺纹／竹节」，1 波瓣读成「花生」，眼睛否决（E 诚实条款：视觉证据 > 数学）
笔宽渐变 L（上宽下窄）一次振幅衰减落成细线无缺口、很干净，但整体读作「书法／羽毛」，语义指向弱，且下段过细影响小尺寸
均衡器 L（基线 + 三振幅柱）最直白的声音→文字图解撞脸风险高（直接落进音频 App 通用语汇），且三柱读成柱状图，不是品牌
句点嵌在转角负空间内一个字落在句子里点在大片留白里漂浮，构图失衡，与横笔的关系讲不清
净 L + 顶段着色极简，气质克制装饰性着色无语义绑定（F §1：装饰 = 杂质），删掉它故事不塌 → 该被删
