========================================================================
  FayeLong 英语学习网站   —— 使用说明
========================================================================

版本：{{VERSION}}      构建日期：{{BUILD_DATE}}      交付模式：{{MODE}}

这是一个「跟着音频做精听 / 听写」的本地学习网站。所有数据都保存在你自己的
电脑里；语音识别用本机离线模型；只有「逐句翻译」和「单词在线兜底释义」会用
到网络上免费的翻译服务。


------------------------------------------------------------------------
一、第一次使用（只需要 3 步）
------------------------------------------------------------------------

  第 1 步  把整个 FayeLong 文件夹放在一个**路径不含中文和空格**的位置，
           例如  D:\FayeLong      （放在桌面也可以，但路径越简单越稳）

  第 2 步  双击  启动 FayeLong.bat

  第 3 步  首次启动会自己检查环境；如果提示缺少「语音识别模型 / 离线词典」，
           按提示输入 y 让它自动下载（合计约 1.3GB，国内镜像，视网速需要几分钟）。
           下载完成后浏览器会自动打开，就可以开始用了。

  提示：启动后会弹出一个黑色命令行窗口，这是**服务窗口**，不要关掉它。
        关掉它 = 停止服务。

  ── 不想看到黑窗口？ ──────────────────────────────────────────────
  双击  静默启动 FayeLong.vbs
        · 服务在后台启动，没有窗口；浏览器照样自动打开
        · 停止服务：双击  停止 FayeLong.bat
  双击  安装开机自启.bat
        · 以后每次开机，FayeLong 都会自动在后台运行
        · 使用：浏览器访问  http://127.0.0.1:8000
        · 取消：双击  取消开机自启.bat
  （静默模式下的所有输出写在 data\logs\console.log，排错时看它。）


------------------------------------------------------------------------
二、怎么开始学
------------------------------------------------------------------------

  1) 导入素材
     进入首页「媒体库」，把 mp3 / wav / m4a / flac / mp4 / mkv 等音频或视频
     直接拖进页面，或者点击上传按钮选择文件。
     也可以把文件放进   data\media\audio\   文件夹，然后在页面点「从收件箱导入」。

  2) 等待自动处理
     系统会自动完成：提取音轨 → 语音识别出英文原文 → 逐句翻译成中文 →
     给每句话裁一段独立音频。页面顶部会显示进度。

  3) 开始听写
     点开素材进入学习页：
       · 点句子卡片上的播放键，只听这一句，可以 0.5x~1.5x 变速；
       · 在输入框里把听到的内容打出来，按回车提交；
       · 系统逐词比对，标出多写 / 少写 / 拼错的词，并给出正确率；
       · 「循环」按钮可以单句循环；「A-B」按钮可以只反复听一句话里的一小段；
       · 点原文里任意一个单词，会弹出音标、释义、词形变化，可一键加入生词本。

  4) 复习与整理
     · 顶部「笔记」可以查看这个素材所有句子的笔记，并能导出 Markdown；
     · 左侧「生词本」可以搜索、改释义、标记已掌握、删除、导出 Markdown；
     · 生词本里点「开始练习」可以做三种练习：
         看中文写英文（手输拼写）、看英文选释义（四选一）、听发音写单词（听写）。
       还能选练习范围与题量，答错的词会单独列出来，可以只重练错题。
     · 生词本每一条右边都有小喇叭，点一下就能听英文发音。


------------------------------------------------------------------------
三、数据在哪，怎么备份 / 换电脑
------------------------------------------------------------------------

  所有数据都在   FayeLong\data\   目录里：

      data\app.db        学习数据（素材信息、句子、听写记录、生词本、笔记）
      data\media\        你导入的素材与处理结果（转码音频、句子切片）
      data\models\       语音识别模型（随包资源，不需要备份）
      data\dict\         离线词典（随包资源，不需要备份）
      data\logs\         运行日志（出问题时把它发来即可定位）
      data\backups\      更新前自动备份的 app.db（保留最近 5 份）

  备份 / 迁移到另一台电脑：把  data\app.db  和整个  data\media\  拷贝过去即可。
  （把整个 FayeLong 文件夹拷过去当然也可以，只是会多拷 1.3GB 的模型和词典。）


------------------------------------------------------------------------
四、升级到新版本（不会丢失你的数据）
------------------------------------------------------------------------

  ⚠️ 请不要把新版压缩包直接解压覆盖旧目录 —— 请用下面的办法，
     它只替换程序文件，你的学习数据原样保留。

  第 1 步  把新版压缩包解压到一个**新的空文件夹**，例如  D:\FayeLong-new

  第 2 步  先双击旧目录里的「停止 FayeLong.bat」，停掉正在运行的服务

  第 3 步  双击新文件夹里的「更新 FayeLong.bat」，
           然后按提示输入旧安装目录（例如 D:\FayeLong），
           或者干脆把旧目录用鼠标拖到这个文件上

  第 4 步  看到「更新完成」后，双击旧目录里的「启动 FayeLong.bat」即可

  更新脚本会自动完成这些事：
      · 自动记住 / 定位旧安装目录（上次装在哪它知道）
      · 先把 data\app.db 备份到 data\backups\（保留最近 5 份，可回退）
      · 替换 app / static / scripts，增量更新 runtime
        （没变化的文件会跳过，所以通常只要几秒到几十秒）
      · 只有缺失的模型 / 词典才会补，已有的一律不动
      · **绝不改动** data\app.db、data\media\、data\logs\、data\backups\

  还想更省流量？让开发者用 packaging\build-update.ps1 产出「更新包」——
  只含程序文件，几 MB ~ 几十 MB，不必每次重发 1.3GB 的模型与词典。


------------------------------------------------------------------------
五、常见问题
------------------------------------------------------------------------

  Q1. 双击后黑窗口一闪就没了？
      说明启动时出错。请在该文件夹按住 Shift + 右键 →「在此处打开 PowerShell /
      终端」，手动执行：
          runtime\python\python.exe scripts\launcher.py --check
      它会告诉你具体缺什么。也可以把 data\logs\app.log 发给开发者。

  Q2. 提示「端口 8000 被占用」？
      不用管，启动器会自动改用 8001、8002 … 并打开对应地址的浏览器。

  Q3. Windows 提示缺少 VCRUNTIME140.dll / MSVCP140.dll？
      这是微软的 VC++ 运行库。交付包已内置这几个 DLL；若仍报错，请安装
      「Microsoft Visual C++ 2015-2022 可再发行组件包 (x64)」后重试。

  Q4. 杀毒软件报警或拦截？
      正常现象：本程序包含 Python 解释器和 ffmpeg 等可执行文件，且会开启本地
      网络端口，容易被误判。请选择「允许 / 信任」，或把整个文件夹加入白名单。

  Q5. 没有网络可以用吗？
      可以播放、听写、查词（词典是离线的）。只有「逐句中文翻译」和
      「单词兜底释义」需要联网；翻译失败时原文仍在，可手动补充中文。

  Q6. 翻译结果为空 / 个别句子没译出来？
      在线翻译接口有配额限制。可在学习页点该句的「重译」重试；
      也可以手动编辑中文译文并保存。

  Q7. 识别很慢？
      识别在本机 CPU 上跑，长音频需要时间（约 1 分钟音频 ≈ 10~30 秒）。
      素材越短、越清晰越快。可在 backend\.env 里把 FAYELONG_WHISPER_MODEL
      改成 base 或 tiny 以提速（精度略降）。

  Q8. 想清掉某条素材占用的空间？
      在学习页点「清理切片」可删掉句子音频切片（不影响原文与笔记，
      重新识别或重新导入会再生成）。

  Q9. 升级到新版本后，我的数据还在吗？
      在。更新脚本只替换程序文件，全程不碰 data\ 目录；而且它还会先把
      data\app.db 备份一份到 data\backups\，万一新版有问题能回退。

  Q10. 用「静默启动」后，怎么知道服务起没起来？怎么停？
      浏览器能打开 http://127.0.0.1:8000 就说明起来了。
      停止服务：双击「停止 FayeLong.bat」。
      打不开的话，看 data\logs\console.log（静默模式的输出都写在这里）。

  Q11. 开机自启装上了，想临时停一下？
      双击「停止 FayeLong.bat」即可；下次开机它还会再起来。
      彻底不要：双击「取消开机自启.bat」。


------------------------------------------------------------------------
六、卸载
------------------------------------------------------------------------

  本程序是绿色版，不写注册表、不装服务：
      0) 若装过开机自启，先双击「取消开机自启.bat」；
      1) 双击「停止 FayeLong.bat」停止服务；
      2) 直接删除整个 FayeLong 文件夹即可。
  如果想保留学习记录，删除前先把 data\app.db 与 data\media\ 拷出来。


------------------------------------------------------------------------
七、给开发者的备注（普通使用可忽略）
------------------------------------------------------------------------

  · 自检：      runtime\python\python.exe scripts\selftest.py
  · 仅检查：    runtime\python\python.exe scripts\launcher.py --check
  · 指定端口：  启动 FayeLong.bat --port 8100
  · 静默启动：  runtime\python\pythonw.exe scripts\launcher.py --silent --no-browser
  · 就地更新：  runtime\python\python.exe scripts\update.py --target D:\FayeLong
                 （加 --dry-run 只预演、不改任何文件）
  · 补资源：    runtime\python\python.exe scripts\bootstrap.py
                 （--model 只下模型，--dict 只下词库）
  · 接口文档：  服务启动后访问 http://127.0.0.1:8000/docs
  · 日志：      data\logs\app.log（后端）、data\logs\console.log（静默模式输出）
  · 内置 Python：runtime\python\python.exe（3.13 嵌入版，已预装全部依赖）
