## 2. 字体阶梯

| 层级 | 字号 / 行高 | 字重 | 备注 |
|---|---|---|---|
| 显示 H1 | 42 / 1.24（移动 26） | 800 | 中文不做负字距，`letter-spacing: .3px` |
| H2 区块标题 | 17 / 1.45 | 700 | 卡片大标题同 |
| 卡片标题 | 15 / 1.45（移动 14） | 700 | 最多 2 行 |
| 正文 | 14 / 1.75 | 400 | 中文行高 1.75 |
| 元信息 | 12.5 / 1.6 | 400 | `--ink-3` |
| 数字 | `tabular-nums` | 700–800 | 统计值、进度百分比 |

字体栈：`-apple-system → PingFang SC → Microsoft YaHei → Noto Sans SC`（纯系统字体，零外网依赖）。

## 3. 形状语言

- 描边：**统一 2px `--ink`** —— 这是与 logo 共享的核心识别特征，任何卡片/按钮/输入框都必须有
- 圆角只有 3 档：卡片 `20px`、控件 `14px`、按钮与标签 `999px`（药丸）
- 硬阴影：只给"可点的东西" —— `0 3px 0 var(--ink)`，hover 抬 1px、active 压平（贴纸按下去的手感）
- 间距基数 4，实际取 8 / 12 / 14 / 18 / 22 / 26 / 34

## 5. 断点表

| 断点 | 变化 |
|---|---|
| **≥768px（PC）** | 顶栏四段式（品牌 / 导航 / 搜索 / 头像）；Hero 左文右图；统计 3 列；课程卡片 `auto-fill minmax(268px)` 自适应 2–4 列；卡片竖排（封面在上） |
| **≤767px（移动）** | 导航与搜索收成图标；Hero 纵向、logo 置顶 104px；统计 2 列（第三张横排）；课程卡片变**横排列表行**（86px 方封面在左）；底部 Tab Bar 出现；状态自检区隐藏 |

实现方式：container query（`.app` 为容器），同一份 DOM 在 1320px 下是 PC、在 390px 下是移动 —— 手机预览里的那份是 JS 克隆的同一节点，不是另写的页面。

## 7. 默认项与近似项声明

- **平台**：响应式双端（PC 为主稿，移动为并列形态）—— 原需求只说「网站 UI」，这是代答项
- **页面**：只出「媒体库首页」，用于锁风格；学习页 / 生词本 / 练习页在 token 锁定后铺开
- **内容**：课程名（TED-Ed、BBC 6 Minute English、雅思听力 Section 3、Friends、All Ears English、60-Second Science）与时长为真实感占位，非真实数据
- **风格参照**：无外部品牌参照，全部视觉从 logo 直接提取；未克隆任何既有产品
- **字体**：系统字体栈，未引入需授权字体
- **图标**：全部手写内联 SVG（2px 圆头描边），单一线性家族，`currentColor` 继承文字色
- **图片**：零外网依赖；logo 以 base64 内联进 HTML，渐变/波形均为 CSS + SVG 绘制

## 8. 成稿自检

- 移动版：按钮 48px、chip 40px、Tab 48px ≥44 ✓ / 单列流 ✓ / 底部 Tab 吸底 + 安全区 `env()` ✓ / 卡片横排节省高度 ✓
- PC 版：按钮 hover/focus/active/disabled 四态 ✓ / 卡片 hover 四态 ✓ / `max-width: 1320px` 限宽 ✓ / 骨架屏·空态·错误态 ✓ / `:focus-visible` 3px 描边 ✓
- 双端：正文对比度 AA ✓ / 层级 ≤3 ✓ / 间距 4 的倍数 ✓ / 圆角 3 档 ✓ / 中文行高 1.75 ✓ / 无外网资源 ✓ / 无 lorem ipsum ✓
