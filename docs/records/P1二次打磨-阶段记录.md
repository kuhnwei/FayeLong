## 踩过的坑（值得记住）

1. **字母圆污染 `textContent`**（D1）：练习选项加 `A/B/C/D` 后，`option.textContent` 变成 `"Acompete"`，而 `verify_vocab_practice` 用 `textContent.startsWith(正确释义)` 定位选项 → 全部点错、反馈 wrong。修法：字母改用 `.opt-key::before { content: attr(data-key) }` 伪元素渲染，不进入 `textContent`。
2. **祖先回溯找错层**（D2）：`verify_category` 的 `findRowByTitle` 从标题向上找「含 `/study/` 链接的祖先」，行布局里正好是整行；卡片布局先命中**内容区**，而勾选框在封面区 → `querySelector('input[type=checkbox]')` 返回 null。修法：卡片根加 `data-media-row`，脚本优先读锚点、保留旧逻辑兜底。
