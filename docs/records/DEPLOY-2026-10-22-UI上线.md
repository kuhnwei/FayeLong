## 三、发现并修复的问题（重要）

**现象**：`update.sh` 报 health 200，但访问 `/` 返回 JSON：
`{"hint":"前端尚未构建：在 frontend-vue 目录执行 npm run build 后即可单端口访问"}`

**根因**：部署口径与代码不一致。
- `backend/app/core/config.py` 的 `STATIC_CANDIDATES = (ROOT_DIR/"frontend-vue"/"dist", ROOT_DIR/"static")`
- `deploy/linux/update.sh` 的产物落在 `$APP_ROOT/frontend/dist`
- 两者不交集 → 后端找不到含 `index.html` 的目录 → 回落 JSON 兜底

**修复**：
1. 云端立即建软链：`ln -sfn /opt/fayelong/frontend/dist /opt/fayelong/frontend-vue/dist`，重启后 `/` 恢复 `text/html`
2. 把软链写进 `deploy/linux/update.sh`（原子替换之后，幂等），并已同步到云端 `/opt/fayelong/deploy/linux/update.sh`

**教训**：`health 200` 不能证明前端可用，必须验「`/` 的 content-type + 引用的 assets 文件名」。
