### 四个必须记住的坑（都写进计划 §5 与 env.py）
1. **`alembic.ini` 必须纯 ASCII**：alembic 用 `encoding="locale"` 读 ini，中文 Windows = cp936，
   UTF-8 中文注释会在**任何迁移执行前**抛 `UnicodeDecodeError`；`PYTHONUTF8=1` 也救不了（走 `locale.getencoding()`）。中文说明放 `env.py`。
2. **Git Bash `/tmp/x.db` → `Path.resolve()` 变成 `D:\tmp\x.db`**，会「迁移成功」到新建的空库。一律 `"$(cygpath -w …)"`，并核对 env.py 打印的目标库 URL（该日志别删）。
3. **基线必须显式 DDL + `inspect()` 跳过已存在表**，否则老库 `upgrade head` 直接 `table already exists`。
4. **`compare_server_default` 必须保持关闭**：`created_at`×6 / `notes.updated_at` 模型只有 `func.now()`、`marks` 只有客户端 `default=""`，开启后**连正确迁移的空库**也会永久报 `modify_default`，门禁被假阳性卡死。

- 结果：**240 passed, 1 skipped**（原 184 + 52 + 4）；契约 **34/42** 不变；真库 md5/指纹未变

### 三个把计划原文推翻的设计（都是对的）
1. **必须拆 stage，不能整条链进一个池**：`process_media` 是 transcode→asr→translate→clip 一条链，翻译那几分钟 IO 占 CPU 槽；云端 cpu=2 时两个媒体进 translate 就把池占满 → G3-③ 物理不可能通过。改成 4 个 stage job，`done` 时**同一事务**插入下一 stage。
2. **崩溃恢复判据必须是 OR**：`租约超时 OR worker 不在在线集合`。只靠 TTL 时 `kill -9` 后要等满 120s；OR 分支让重启后 ~8s 接管（实测 9.4s）。
3. **web 三态 `FAYELONG_WEB_INPROC_WORKER=off|auto|on`**：计划说「web 不再跑长任务」，但云端只起一个 uvicorn、开发常只跑 `start-backend.bat`，worker 不在时上传会永远 pending 且**无报错**（本阶段不能改前端、不能加 503）。`auto` = 5s 后接管、worker 上线让位；防双份靠 DB 原子 claim + fencing，不靠 flag。

### ⭐ 本轮最重要的 bug（QA 抓住，P1）
**fencing 在写回路径失效**：`worker.py` 的 `finish_ok/finish_failed` 传的是 `db.get(Job)` 读回的**当前归属**，不是 claim 时快照。后果：老执行者迟到的 `handle_success` 会把**接管者正在跑的**任务写成 `done` 并顺手入队下一 stage；迟到的 `handle_failure` 把接管者打回 `pending` 并串上自己的错误。修法：`_fence()` 返回 `SimpleNamespace` 快照（**不能**给 `fresh.attempts` 赋值——ORM dirty 会把 attempts 计数器 flush 坏）。
- 工程师自补**同源第二处**：`mark_terminal_failure()` 原来**先**无条件写 media、**再**看 `force_failed` 返回值 → 即使 job 轴被拒，media 仍被污染。改成先 fence 再写 media、同一 commit。
- 教训：**「两轴一起收敛」必须由同一张 fence 保护**，只守写回入口不够。

### 判别力陷阱（写进测试注释）
- G3-③ 的断言（翻译早于 ASR 结束 + 区间重叠）**只在 CPU 池=1 有判别力**。矩阵 cpu∈{1,2,4,8}：cpu≥2 时把 translate 误放回 CPU 池**抓不到**（ASR 只占 1 槽，3×0.05s 翻译挤得进剩余槽）。
- `cpu_peak<=1` / `io_peak<=2` 是**恒真的容量检查，不是判别证据**。
- `os.cpu_count()` **不识 cgroup** → `auto` 在容器/云主机不可依赖；云端 unit 显式钉 `JOB_CPU_THREADS=1`（恰好也是唯一有判别力的档位）。
