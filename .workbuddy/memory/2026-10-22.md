### P4-4 默认降级（ADR 那个「付费点」冲突的解法）
`FAYELONG_GRADING_PROVIDER=off` **默认** ⇒ 零付费、离线可用，产出参考范文 + 评分标准 + 自评清单，`status='degraded'`（**成功态**，job `done` 而非 `failed`）。想真批改配 `FAYELONG_GRADING_*` 即可，不改代码。
- 缓存 key = `sha1(question_id + "\x00" + JSON(归一化作答, sort_keys))`；**降级结果不入缓存**（否则「临时关 provider」会被固化成永久结论）

- **`ungraded ≠ degraded`**：前者「判不了」，后者「判了但走降级包」；**`pending` 只数「还会被 worker 判出来」的题**，`ungraded` 不算 —— 否则前端为一道永远判不出的题永久轮询

- 日配额落 `settings` KV；「网络失败也计 1 次」是保守口径（防持续失败绕过上限）；⚠️ 读-改-写非原子，IO 池并发可能**偶尔少计**（绝不多计），个人自用可接受

## 🔴 云端暴露的致命兼容缺陷（本地 3.13 全绿也测不出）
`_PoolRunner`（`threading.Thread` 子类）把停止信号命名为 `self._stop = Event()`，与 `Thread._stop()` **同名**。
- CPython ≤3.12：`Thread._wait_for_tstate_lock()` 在 join 收尾调 `self._stop()` → `TypeError: 'Event' object is not callable`，**worker 一 stop 就崩**（systemd 表现为直接退出，且 journal 里没有明显线索）
- CPython 3.13：移除了那条内部调用 → 本地 376 条测试全绿
- 修法：改名 `_stop_event` + 结构性守卫用例（实例 `__dict__` 不许出现 Thread 内部**方法名**）
- ⚠️ **守卫自己踩了两个坑**：① 只遍历 `worker._runners`，而它在 `start()` 前是空列表 → **空集合上恒真**；② 把 `_invoke_excepthook` / `_is_stopped` / `_tstate_lock` 算作违规会误伤（这些是 `Thread.__init__` 写进实例的正常属性）
- ⭐ **教训**：**云端 venv 是 Python 3.12，本地/打包版是 3.13** —— 凡涉及 CPython 内部行为（线程、contextvars、asyncio）的改动，本地全绿 ≠ 云端能跑。以后这类改动要在云端 venv 上跑一次冒烟。
