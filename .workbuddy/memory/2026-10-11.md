### 两个必须记住的兼容性坑（都已在代码里绕开）
1. **PyAV 版本不兼容**：faster-whisper 1.2.1 内部调用 `av.open(..., metadata_errors=...)`，PyAV 19 已移除该参数 → 传「文件路径」会 `TypeError`。
   解决：**传 numpy 数组**。标准音频固定 16k/单声道/s16，用标准库 `wave` 直接解码（非规范 wav 时用 ffmpeg 解码裸 PCM 兜底），既绕开问题又省一次重复解码。
2. **huggingface_hub 2.x 移除了 `endpoint` 参数**（`hf_hub_download` / `list_repo_files` 都没有了）→ 不要依赖它下载模型。
   解决：直接用镜像 REST 接口 + `urllib`：`GET {endpoint}/api/models/{repo}` 列文件 → `GET {endpoint}/{repo}/resolve/main/{file}` 下载，自带断点续传与字节级进度。

## 第六轮：M3 单句听写页（v1.5）— 已交付并验证

### 核心算法：词级标红（`services/dictation.py`，纯函数无 I/O）
- 分词保留 **`display`（带标点/原大小写）+ `norm`（归一化）双份** → 判分忽略标点，界面仍原样显示 `letter.`。
- 归一化：`’→'`、可选小写、只留 `[0-9a-z']`（`don't` 不拆）；`letter.` ≡ `letter`、`Ask` ≡ `ask`。
- 对齐用 `difflib.SequenceMatcher.get_opcodes()`；`replace` 块做二次分配：成对记 `wrong`，多出的记 `missing`/`extra`。
- 输出四类：`correct`（正常）/ `wrong`（红+波浪线，显示用户写的词）/ `missing`（红虚线，显示漏掉的词）/ `extra`（灰删除线）。
- 正确率 = 正确词数 / 标准答案词数 × 100%。
- **易踩的坑**：多写词不参与正确率分母 → 「正确率 100% 但多写一个词」会被误判为已掌握。
  故 `is_correct = 正确率 ≥ dictation_pass_accuracy(默认100) 且 extra == 0`。

### 关键设计决策
1. **判定权只在服务端**：`POST /api/attempts` 是唯一判定源，前端纯渲染 token，避免两套 diff 实现漂移。
2. **答案零泄漏**：原文/翻译隐藏时**不渲染进 DOM**（实测 `innerText` 不含句子原文），否则 F12 就能抄答案。
3. **算法与聚合分层**：算法 `services/dictation.py`（纯函数）/ DB 聚合 `services/study.py`（`SentenceStat` 折叠）。
4. **提交后就地更新统计**：接口返回该句累计统计，前端用 `StatOverride` 叠加，不重拉媒体详情。
5. 配置新增：`dictation_ignore_case` / `dictation_ignore_punctuation` / `dictation_pass_accuracy`。
