## 第六轮：M3 单句听写页（v1.5）— 已交付并验证

### 核心算法：词级标红（`services/dictation.py`，纯函数无 I/O）
- 分词保留 **`display`（带标点/原大小写）+ `norm`（归一化）双份** → 判分忽略标点，界面仍原样显示 `letter.`。
- 归一化：`’→'`、可选小写、只留 `[0-9a-z']`（`don't` 不拆）；`letter.` ≡ `letter`、`Ask` ≡ `ask`。
- 对齐用 `difflib.SequenceMatcher.get_opcodes()`；`replace` 块做二次分配：成对记 `wrong`，多出的记 `missing`/`extra`。
- 输出四类：`correct`（正常）/ `wrong`（红+波浪线，显示用户写的词）/ `missing`（红虚线，显示漏掉的词）/ `extra`（灰删除线）。
- 正确率 = 正确词数 / 标准答案词数 × 100%。
- **易踩的坑**：多写词不参与正确率分母 → 「正确率 100% 但多写一个词」会被误判为已掌握。
  故 `is_correct = 正确率 ≥ dictation_pass_accuracy(默认100) 且 extra == 0`。

### 关键设计决策
1. **判定权只在服务端**：`POST /api/attempts` 是唯一判定源，前端纯渲染 token，避免两套 diff 实现漂移。
2. **答案零泄漏**：原文/翻译隐藏时**不渲染进 DOM**（实测 `innerText` 不含句子原文），否则 F12 就能抄答案。
3. **算法与聚合分层**：算法 `services/dictation.py`（纯函数）/ DB 聚合 `services/study.py`（`SentenceStat` 折叠）。
4. **提交后就地更新统计**：接口返回该句累计统计，前端用 `StatOverride` 叠加，不重拉媒体详情。
5. 配置新增：`dictation_ignore_case` / `dictation_ignore_punctuation` / `dictation_pass_accuracy`。

### 音节条目陷阱（重要）
- ECDICT 除正常词条外还有**音节拆分条目**（`hel-lo`、`-running`、`chil-dren`、`bet-ter`），它们的 `sw`（去符号规范化词形）与正常词相同。
- 只按 `sw = ?` 查询会优先命中这些拆分条目：实测 `children` 返回「字组拆分到两个音节中去」，`hello` 返回 `hel-lo`。
- **修正**：`services/dict.py::_query` 改为三级优先查询，结果按 `collins DESC, frq DESC` 排序：
  ① `word = ?`（走 word 唯一索引，必然命中正常词条）→ ② `sw = ? AND word NOT LIKE '%-%'` → ③ `sw = ?`。
- 索引现状：`word` UNIQUE（stardict_2 / sd_1）、`sw` 有索引（stardict_3）→ 三级查询都走索引，很快。

### 词形还原（两级）
1. **exchange 反查**（首选、最准）：命中词条后若 exchange 含 `0:`（原型）则用原型再查一次，`via=exchange`。
   实测 `received→receive`、`running→run`、`children→child`、`studies→study`、`went→go`、`better→good`、`Americans→American` 全部正确。
2. **lemminflect + 规则兜底**：候选原型**必须能命中词库**才采用（`via=lemminflect`/`rule`），避免误还原。

## 静默启动 + 就地更新（同日晚，第三批需求）

### 需求原文
> 「1. 实现静默启动；2. 交付包实现可在旧版本安装目录下进行更新，避免新版安装导致数据被覆盖」

两项都属于**交付链（`packaging/`）**。关键约束：用户长期目标是「一台没有开发环境的 Windows 笔记本（8GB）」，
`data/` 里是几个月积累的学习记录（`app.db` / `media/` / 生词本 / 笔记），**覆盖即不可逆丢失**。

### 需求 1：静默启动
- **原理**：Python 嵌入版自带 `pythonw.exe`（GUI 子系统，不创建控制台窗口），其 `sys.stdout` / `sys.stderr` 为 `None`。
  据此实现 `wants_silent(explicit)` —— **自动判定**，用户与快捷方式都不必记参数。
- **输出必须有落盘**（否则「静默 = 完全失明」）：`redirect_stdio_to_log()` 把标准流接到
  `data/logs/console.log`（UTF-8 / `buffering=1` / 超 2MB 轮转为 `console.log.1`）。
- **`input()` 在 pythonw 下抛 `RuntimeError`**（不是 `EOFError`）→ 捕获范围扩为 `(EOFError, OSError, RuntimeError)`，
  静默时改为「已自动跳过」提示，避免卡死或崩在看不见的地方。
- **安装记录**：`%LOCALAPPDATA%\FayeLong\install.txt` 写 `<root>\n<version>\n<时间>`，
  **必须 UTF-16**（因为 VBS 用 `OpenTextFile(path, 1, False, -1)` 按 BOM 识别读取）；
  同时写 `<root>/data/install.json`（UTF-8，只记版本与时间、**不记路径**，便于整体迁移 `data/`）。
- **新增文件**（4 个用户可见文件 + 2 个 bat 配套）：
  `静默启动 FayeLong.vbs`、`FayeLong-Autostart.vbs`（开机自启本体，`--silent --no-browser`）、
  `安装开机自启.bat` / `取消开机自启.bat`（复制/删除到 `%APPDATA%\...\Startup`）。
- **两个 vbs 的定位策略不同**：静默启动按**自身所在目录**；开机自启先按自身目录 → 再读
  `install.txt` 第 1 行 → 都找不到就 **`WScript.Quit 0` 静默退出**（开机自启不该弹窗打扰登录）。

### 需求 2：就地更新（只换程序、绝不碰数据）
- **分类同步策略**（`scripts/update.py`）：
  - 整目录替换（先删后拷）：`app/`、`static/`、`scripts/`
  - 增量复制（内容相同则跳过）：`runtime/python`、`runtime/ffmpeg`、`tools`
  - 覆盖顶层文件：5 个 bat + 2 个 vbs + `使用说明.txt`
  - 数据资源**只补缺失**：`data/models`、`data/dict`
  - **全程不碰**：`data/app.db`、`data/media/`、`data/logs/`、`data/backups/`
- **⚠️ 修掉一个真实缺陷**：增量判断原先只比**文件大小**，实测存在「尺寸相同、内容不同」的文件
  （测试夹具里新旧 `python.exe` 都是 8 字节）→ 会被当「未变化」跳过，更新不完整。
  改为 `_same_content()` **分块比对**（1MB chunk，遇差异立即返回）。
  性能实测：比对 461MB 需 **0.55s**，读完全部 6126 个文件 / 329MB runtime **< 1s**。
- **更新前必须先停服务**：读旧目录 `data/logs/fayelong.pid` → `taskkill /PID /T /F` → `sleep 0.8` 释放句柄，
  否则 Windows 因文件被占用拒绝覆盖（运行中的 `python.exe` 尤其明显）。
- **数据备份**：`data/app.db` → `data/backups/app-<旧版本>-<时间戳>.db`，保留最近 **5** 份（`KEEP_BACKUPS=5`）。
- **安全护栏**（任一不过即报错退出、**不做任何写入**）：目标必须「像」安装目录（有 `app/` 或 `runtime/python/python.exe`）；
  目标不能等于或嵌套新包目录（`resolve()` 后比较及父子关系）；支持 `--target` / `--dry-run`。

### 踩坑
- **WSH 不认 UTF-8**：含中文的 `.vbs` 必须存 **UTF-16LE + BOM**，否则乱码甚至语法错误；
  源文件（`packaging/files/*.vbs`）保持 UTF-8，**构建时转 UTF-16LE**（`build.ps1` 的 `Write-TextFileUtf16`）。
- **`.ps1` 必须带 UTF-8 BOM**：`build-update.ps1` 首次无 BOM，WinPS 5.1 按本机 GBK 解码中文，
  报出十来个假语法错误（`意外的标记“)”` / `缺少右“}”`）。写入时用 `encoding='utf-8-sig'` + CRLF 即解决。
- **子进程中文乱码**：`check_syntax.py` 按 UTF-8 输出、PowerShell 按 GBK 解码 →
  调用前设 `[Console]::OutputEncoding = UTF8` 与 `$OutputEncoding = UTF8`。
- **测试脚本自身的坑（非产品 bug）**：vbs 里 `sh.Popup` 是**跨 3 行的续行语句**，
  只把首行改成 `rem` 会让后续行变成游离语句 → `缺少语句结束`。改为正则**整段剥离**。
