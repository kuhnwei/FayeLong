### 已确认决策

### 关键实现
- **模型**（`entities.py`）：User 加 `role/is_active/token_version`；Attempt/Note/Vocab/PracticeSession 加 `user_id`（**声明在表末尾**——ALTER 只能加列尾，放末尾才能双轨列顺序一致）；新增 `SentenceMark` 表。
- **user_id 外键刻意 NO ACTION**（不带 ondelete）：SQLite 的 `ALTER ADD COLUMN` 无法表达 ON DELETE CASCADE（反射成 NO ACTION），且软删除策略下物理删除不发生，NO ACTION 反而更安全。唯一约束用**显式唯一索引** `Index(unique=True)` 而非 UniqueConstraint（后者生成 sqlite_autoindex 无法 DROP/CREATE，无法双轨表达）。
- **迁移** `0004_multiuser.py`：幂等（先反射再动作），回填老唯一账号 user_id、迁 sentences.marks → sentence_marks、notes 唯一索引切换。
- **双轨自愈**（`db.py`）：`_ADDED_COLUMNS`/`_INDEXES` 扩展 + `_ensure_multiuser_data()`（notes 索引切换 + 回填 + marks 迁移），云端/打包版非 alembic 也能补。
- **认证**：login 按 username 查（`get_by_username`）+ dummy_user 恒定时；token 加 `ver`（token_version），改密/重置/停用/软删 bump 使旧 cookie 立即失效；guard 回查 User 注入 `request.state.user_id`。
- **数据隔离**：attempts/notes/vocab/stats/sessions 加 user_id 过滤与 IDOR 校验；media/sentences/categories 写操作限 `require_admin`；marks 拆独立个人端点 `PUT /api/sentences/{id}/marks`。
- **admin API** `api/admin.py`（7 端点，挂 `/api/admin/*` 不落 `/api/auth/`）+ `services/admin_stats.py`（按 user_id 聚合）+ 最后一个 admin 保护。
- **前端**：抽 `api/queryClient.ts`（解循环依赖）；`/admin/users`、`/admin/stats` 路由 + `beforeEach` 角色守卫；Layout/AccountMenu 按 role 过滤；新增 UsersPage/ComparePage；MediaLibraryPage 上传/批量/分类管理 `v-if="isAdmin"`；request.ts 加 403（不广播 unauthorized）。

## 站点切换 HTTPS：https://fayelong.com.cn（提交 27500b0）

- **决策变更**：用户原话要求「基于 Certbot」，但线上跑的是 **Caddy v2.11.4，机器上根本没有 nginx / certbot**。给了三条路（Caddy 内置 / nginx+certbot 全替换 / certbot 签发+Caddy 加载），用户拍板走 **Caddy 内置 ACME**。→ 后续任何人再提 certbot，先看这条。
- **改动**：`deploy/linux/Caddyfile.site` 站点地址 `:80` → `fayelong.com.cn`；加 HSTS `max-age=31536000`（**刻意不加** includeSubDomains/preload，留撤销余地）；加 `http://114.132.173.241` 精确匹配块 301 到域名（老书签兼容，且不会抢 ACME 校验路径）。
- **续期机制**：Caddy 后台每 12h 巡检，走 LE 的 **ARI** 建议窗口。实测日志 `got renewal info window_start=1797824786` ≈ **2026-12-21** 续期，证书 2027-01-21 到期。**没有 cron、没有 systemd timer、没有 certbot**。Caddy 无强制续期子命令，强制只能删证书目录 + reload（注意 LE 每周 5 次重复签发限速）。
- **云防火墙**：原来只放通 80/22/ICMP，**443 完全没开**。已加 TCP/443 + UDP/443（UDP 是给 HTTP/3 的：Caddy 默认发 `Alt-Svc: h3`，不开 UDP 会每次首访先试 QUIC 失败再退回 TCP）。
- **无需改代码的三条证据**（混合内容风险已排除）：① `frontend-vue/src/api/request.ts` 里 `BASE = '/api'` 是相对路径，同源不走 CORS；② 线上 bundle 里唯一 `http://` 是 `www.w3.org/2000/svg` 这类 XML 命名空间常量；③ uvicorn 已带 `--proxy-headers --forwarded-allow-ips=127.0.0.1`，`X-Forwarded-Proto: https` 被正确识别。
- **验收**：真实 Chrome（不忽略证书错误）打开 → `https:` + `isSecureContext=true` + 登录门禁渲染 + **0 console.error / 0 失败请求**，协议集合 `h2, h3`。openssl 证书 CN=fayelong.com.cn、issuer `YE2`。`/assets/*` 仍是 `immutable` 强缓存。`systemctl is-enabled caddy` = enabled。
