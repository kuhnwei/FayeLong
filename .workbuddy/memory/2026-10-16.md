## 技术栈选型评估（ADR-001）

**背景**：用户考虑趁早期版本重构。自评主力栈 Java + Vue，现为 Python 3.13 + React 18；未来要加雅思真题模拟 + 多题型单项训练。

**实测的关键事实（后续复用，别再重新统计）**
- 后端 `backend/app`：**42 个 py / 5,739 行**；前端 `frontend/src`：**23 个 ts(x) / 7,564 行**。合计 ≈13.3k 行。
- ⭐ **后端第三方依赖只有 5 个**：fastapi / uvicorn / sqlalchemy / pydantic-settings / python-multipart。其余全是标准库（wave/subprocess/sqlite3/hashlib/hmac/difflib/threading…）。**语言锁定点只有 ASR 一处**。
- ML 依赖隔离在 `requirements-ml.txt`（faster-whisper / ctranslate2 / huggingface-hub / onnxruntime / numpy / **lemminflect**），`services/asr.py` 延迟导入。
- 前端运行时依赖 5 个：react18 / react-router6 / @tanstack/react-query5 / zustand5。**无 Redux / Next.js / 重型 React 生态**。
- **35 个 REST 端点**；**9 张表**；前端 **60 个组件定义 / 635 处 className / 96 处 react-query 调用点**。
- 无 pytest、无单元测试；仅 8 个 CDP e2e（`scripts/verify_*.mjs`）。

**结论（待用户确认）**
- 前端 React → **Vue 3 重写：建议做**。可免费复用约 1,300 行 / 17%（`client.ts` 类型部分、`icons.tsx` 465 行 SVG、`utils/*` 113 行；`useClipPlayer` 是原生 Audio API，与框架无关，可近乎照搬）。
- 后端 **不换 Java**：ASR 无 Java 等价物 → 必然引入 Python sidecar → 技术栈从 2 涨到 3 + 双运行时，「单一技术栈」目标不可达。whisper.cpp+JNI 是另一条需重新验证标点/词级时间戳/VAD 的风险路径。
- 后端**架构加固才是重点**（比换语言重要）：① 引入 Alembic（现在 9 张表是最便宜时机）② 新增 `jobs` 表 + 独立 worker，CPU 池(ASR/ffmpeg) 与 IO 池(翻译/LLM) 分池 ③ 领域分层 ④ 补测试网 ⑤ health 扩可观测字段。
- 未来 IELTS 用**新表族**（`papers/sections/passages/questions/practice_sessions/responses`），`answer`/`detail` 用 JSON 列；**旧 media/sentences/attempts 不动**，听写降为 `type='dictation'` 的题型之一，历史数据零迁移。
- 题型插件化契约：`QuestionType{code, validate, grade→GradeResult, normalize}` + `GET /api/question-types` 下发清单防前后端漂移。
